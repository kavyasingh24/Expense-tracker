 Spendly – Smart Expense Management System

Spendly is a modern **Expense Management Web Application** built using **Python Flask**. It helps users efficiently manage their daily expenses, set monthly budgets, and gain insights into their spending habits through an intuitive dashboard.

 **Live Demo:** https://expense-tracker-e9u9.onrender.com
---

 Overview

Managing personal finances can be challenging when expenses are recorded manually. Spendly simplifies expense tracking by providing a secure and user-friendly platform where users can record expenses, monitor budgets, and analyze their monthly spending.

##  Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/expense-tracker.git
```

### Move into the project

```bash
cd expense-tracker
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

Mac/Linux

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```
